## Notes

To fully replicate this website offline, you would need to:

1. Download all CSS files listed above
2. Download all JavaScript files
3. Download all images and fonts
4. Update all URLs in the HTML to point to local files
5. Set up a local WordPress installation with the required plugins and theme

The website uses:
- **WordPress Version**: 6.1.1
- **Theme**: Impacto Patronus (Startup)
- **Skin**: Human Rights
- **Page Builder**: Elementor
- **Slider**: Revolution Slider 6.7.20
- **Key Plugins**: TRX Addons, UserPro, Gravity Forms
