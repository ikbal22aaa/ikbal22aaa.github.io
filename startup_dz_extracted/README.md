## Website Overview

**Startup.dz** is the national portal for startups in Algeria (Portail national des startups).

### Key Features Found in the Code:

1. **WordPress-based** - Built using WordPress CMS
2. **Elementor Page Builder** - Uses Elementor for layout design
3. **Responsive Design** - Mobile-friendly with responsive breakpoints
4. **Main Sections:**
   - Header with navigation menu
   - Hero slider (Revolution Slider)
   - Startup label information
   - Algeria Disrupt program
   - Algerian Startup Fund (ASF)
   - A-venture accelerator
   - News/Articles section
   - Footer

### Technologies Used:

- **CMS:** WordPress 6.1.1
- **Page Builder:** Elementor
- **Slider:** Revolution Slider 6.7.20
- **Plugins:**
